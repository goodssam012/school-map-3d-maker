# 학교 3D 안내도 제작기

학교 외형을 고르고 건물을 배치한 뒤 층별 교실 정보를 입력해 3D 학교 안내도를 만드는 앱입니다.

## 주요 기능

- 전체 또는 건물별 외형 템플릿과 색상, 지붕, 창문 지정
- 본관, 별관, 체육관, 강당, 운동장 등 건물과 시설 배치
- 점을 찍어 꺾인 건물까지 직접 그리기, 배치도 사진과 건물 사진 적용
- 정문, 후문, 중앙현관, 건물 출입구, 비상구 편집
- 담장·울타리 모양(철망, 철제, 나무, 낮은 담장, 벽돌, 돌담, 생울타리) 선택과 영역 끌어 한 번에 두르기, 정문·후문 자리 자동 비우기
- 1층 필로티 건물 선택(1층 기둥, 2층부터 교실)
- 운동장 바닥(잔디, 흙)과 육상 트랙 유무 선택
- 층별 복도 위치(아래, 위, 왼쪽, 오른쪽, 가로·세로 가운데) 선택, 빈칸을 복도에 합쳐 ㄱ자·ㄷ자 복도와 홀 만들기, 직접 그린 건물은 복도 칸 자동 생성과 칠하기
- 화장실, 층 연동 엘리베이터, 복도 쪽 계단 배치
- 교실별 칠판 위치 선택과 책상 배열 방향 자동 전환
- 과학실, 음악실, 미술실, 기술실, 가사실, 컴퓨터실, 도서실, 식당 등 종류별 3D 내부 배치
- 교실 크기(반칸~3칸) 선택과 건물 가로 자동 조정
- 격자에서 교실을 끌어 다른 교실 사이에 끼워 넣기
- 칸 합치기로 ㄱ자, ㄷ자 교실 만들기
- 교실 출입문 종류(나무문, 유리문, 양쪽 유리문, 미닫이문, 문 없음)와 위치 선택(평면에서 문 끌어 옮기기), 유리문 현관
- 층별 격자에 교실 위치와 이름 입력, 3D 표찰 자동 변경
- 교실과 출입구 검색, 해당 층 열기와 위치 점 표시
- 방문자용 HTML 파일 내보내기
- 여러 사람이 건물을 나눠 만든 제작 파일 합치기

## 사용 방법

- 브라우저: `maker.html`을 Chrome 또는 Edge로 엽니다.
- 자세한 설명: `사용안내.html`을 엽니다.

제작기는 인터넷 없이 동작합니다. 내보낸 방문자용 HTML은 3D 도구를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 실행파일 만들기

Node.js가 설치된 Windows에서 실행합니다.

```powershell
npm ci
npm run dist
```

`dist` 폴더에 설치 없이 실행되는 exe 파일이 만들어집니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `maker.html` | 제작기 본체 |
| `사용안내.html` | 사용 안내서 |
| `electron/main.js` | 데스크톱 앱 실행 코드 |
| `vendor/` | three.js r147 (MIT 라이선스) |
| `index.html`, `css/`, `js/`, `data/` | 사진 기반 안내도 초기 버전 (보기 전용) |
