3D 학교 안내도 제작기 사용 안내

학교 외형을 고르고, 건물을 놓고, 교실을 입력하면 방문자가 교실 위치를 찾아볼 수 있는 3D 안내도가 완성됩니다.

  1. 1. 스타일학교 이름과 외형 선택
  2. 2. 건물 배치건물, 시설, 소품 놓기
  3. 3. 교실 정보격자에 위치와 이름 입력
  4. 4. 완성확인 후 HTML로 내보내기

시작하기

  1. School3DMapMaker 실행파일을 더블클릭하거나, 폴더의 maker.html을 Chrome 또는 Edge로 엽니다. 실행파일에서는 F1로 이 안내서를 열 수 있습니다.
  2. 처음 열면 예시 건물이 놓인 기본 캠퍼스가 나타납니다.
  3. 화면 위쪽의 1 스타일부터 4 완성까지 차례로 진행합니다. 단계 이름을 누르면 언제든 앞뒤로 이동할 수 있습니다.
준비물: 건물별 층수, 층별 교실 이름과 대략적인 위치를 적은 메모. 큰 화면의 컴퓨터에서 마우스로 작업하는 것을 권장합니다.

3D 화면 움직이기

  • 돌리기: 마우스 왼쪽 버튼으로 끌기 (2단계에서는 건물이 없는 곳을 끌기)
  • 옮기기: 마우스 오른쪽 버튼으로 끌기
  • 확대와 축소: 마우스 휠 돌리기
  • 처음 시점으로: 오른쪽 아래 전체 보기 또는 위에서 보기

1스타일 고르기

  1. 학교 이름을 입력합니다. 본관 간판과 정문에 그대로 표시됩니다.
  2. 적용 대상에서 전체 건물 또는 꾸밀 건물 하나를 고릅니다. 3D 화면에서 건물을 눌러도 선택됩니다.
  3. 외형 템플릿 여섯 가지 중 하나를 고릅니다. 건물을 골랐다면 그 건물에만 적용됩니다.
  4. 필요하면 세부 꾸미기에서 벽, 포인트, 지붕 색과 지붕 모양, 창문 모양을 바꿉니다. 바닥은 전체 건물에서 바꿉니다.
  5. 시작 배치에서 기본 캠퍼스로 시작 또는 빈 부지로 시작을 고릅니다.
건물별 스타일: 개별로 꾸민 건물에는 · 개별 표시가 붙고, 전체 스타일을 바꿔도 그대로 유지됩니다. 다시 맞추려면 그 건물을 골라 전체 스타일로 되돌리기를 누르거나, 전체 건물에서 개별 스타일 모두 해제를 누릅니다.
주의: 시작 배치를 다시 누르면 지금까지 놓은 건물과 교실 정보가 지워집니다.

2건물 배치

새로 놓기

  1. 건물, 시설, 소품 중 분류를 고릅니다.
  2. 놓을 항목을 누르고 지도 위로 마우스를 옮깁니다. 초록색은 놓을 수 있는 자리, 빨간색은 겹치는 자리입니다.
  3. 원하는 곳을 누르면 놓입니다. 소품은 계속 찍어서 놓을 수 있고, 끝내려면 Esc를 누릅니다.
분류항목
건물본관, 별관, 과학관, 도서관, 급식실, 체육관, 강당
시설운동장, 농구장, 정원, 광장, 보행로, 주차장
출입구정문, 후문, 건물별 중앙현관·출입구·비상구
소품나무, 소나무, 화단, 벤치, 가로등, 국기 게양대, 기념비, 울타리

고치기

  • 옮기기: 건물을 마우스로 끕니다.
  • 설정 바꾸기: 건물을 누르면 왼쪽에 이름, 크기, 층수, 층 높이, 색, 지붕, 창문 설정이 나타납니다.
  • 회전, 복제, 삭제: 왼쪽의 버튼을 쓰거나 R, Delete 키를 누릅니다.

새 건물 직접 그리기

  1. 건물 분류에서 새 건물 직접 그리기를 누릅니다.
  2. 지도에서 건물 크기만큼 끌면 사각형 건물이 생깁니다. 가로와 세로는 8m 이상이어야 합니다.
  3. 왼쪽에서 이름, 층수, 색을 입력합니다. ㄱ자 건물은 사각형 건물 두 개를 붙여서 만들 수 있습니다.

배치도와 건물 사진

  • 배치도 사진: 사진 올리기를 누르면 지도 바닥에 깔려, 사진 속 건물을 따라 그릴 수 있습니다.
  • 건물 사진: 건물을 선택하고 건물 사진의 사진 올리기를 누릅니다. 벽면에 입히거나 완성 화면의 소개 사진으로만 쓸 수 있습니다.
사진 공개 전 확인: 학생 얼굴과 이름표가 보이는 사진은 가리거나 동의를 받아 주세요.

정문과 후문

  1. 출입구 분류에서 정문 또는 후문을 누르고 지도에 놓습니다.
  2. 놓은 문을 누르면 이름과 문 너비를 바꿀 수 있고, 끌어서 옮기거나 R로 회전할 수 있습니다.

중앙현관과 건물 출입구

  1. 출입구 분류에서 편집할 건물을 고릅니다.
  2. 외곽 평면의 건물 테두리를 누르면 새 출입구가 생기고, 바로 이름을 입력할 수 있습니다.
  3. 점을 끌면 건물 둘레를 따라 위치가 옮겨집니다.
  4. 목록에서 종류를 중앙현관, 출입구, 비상구 중에서 고르고, 앞면, 뒷면, 왼쪽, 오른쪽 방향도 바꿀 수 있습니다.
  5. 3D로 보기를 누르면 해당 출입구 앞으로 화면이 이동합니다.
건물마다 출입구가 최소 1개 있어야 합니다. 같은 면에서 서로 겹치는 자리에는 놓이지 않습니다.

3교실 정보 입력

  1. 위쪽에서 건물을 고르고 층을 고릅니다. 해당 층이 열리고 내부가 보입니다.
  2. 격자의 빈칸을 누르거나 끌어서 교실 자리를 만듭니다.
  3. 바로 커서가 놓인 이름 칸에 교실 이름을 입력합니다.
  4. 교실 종류를 교실, 특별실, 사무실, 화장실, 기타 중에서 고릅니다. 종류에 따라 3D 가구가 달라집니다.

3D 표찰 확인

이름을 입력하면 화면이 교실 문 앞으로 이동합니다. 다른 교실의 표찰은 표찰 보기로, 층 전체는 층 전체 보기로 볼 수 있습니다. 표찰 앞의 번호는 층과 목록 순서로 자동 생성됩니다.

4완성과 내보내기

교실과 출입구 찾기

  1. 3D 화면 오른쪽 위 검색창에 교실이나 출입구 이름을 입력합니다.
  2. 이름이 정확히 맞으면 자동으로 이동합니다. 여러 곳이 나오면 목록에서 고르거나 Enter를 누릅니다.
  3. 교실을 찾았다면 왼쪽의 표찰 보기를 눌러 그 교실 문 앞으로 다가갈 수 있습니다.

안내도 공개하기

  1. 왼쪽의 ← 전체 건물을 눌러 첫 화면으로 돌아갑니다.
  2. 완성 안내도 내보내기를 누르면 학교이름_3D안내도.html 파일이 내려받아집니다.
  3. 이 파일 하나를 학교 홈페이지나 웹 호스팅에 올리거나 공유합니다. 방문자 화면에는 편집 기능이 없습니다.
공개 전 확인: 출입 통제 구역이나 보안 시설의 이름과 위치, 개인 이름이 들어간 교실명이 없는지 살펴보세요.

저장과 이어서 작업

작업 내용은 사용 중인 브라우저에 자동 저장됩니다. 다만 브라우저 기록을 지우거나 다른 컴퓨터로 옮기면 볼 수 없으므로, 작업을 마칠 때마다 제작 파일을 저장해 두세요.

파일용도만드는 방법
학교이름_제작파일.json나중에 이어서 수정하기위쪽 저장, 다시 불러올 때는 열기
학교이름_3D안내도.html방문자에게 공개하기4단계 완성 안내도 내보내기

이전 안내도 가져오기: 위쪽 열기에서 data/school-data.js를 고르면 이전에 만든 건물과 교실이 제작기로 들어옵니다. 건물은 사각형으로 바뀌고, 겹치는 건물은 빈자리로 옮겨지니 위치를 확인해 주세요.

내용을 고칠 때: 제작 파일을 열어 수정한 뒤 안내도를 다시 내보내고, 공개된 HTML 파일을 새 파일로 바꿉니다. 내보낸 HTML은 수정용으로 다시 열 수 없으니 제작 파일을 꼭 보관하세요.

자주 묻는 질문

3D 화면이 나오지 않아요.

제작기는 인터넷 없이 동작합니다. 브라우저로 열었다면 maker.html과 vendor 폴더가 같은 곳에 있는지 확인하고, Chrome이나 Edge 최신 버전을 사용해 주세요. 내보낸 방문자용 안내도는 3D 도구를 인터넷에서 불러오므로, 외부 인터넷이 막힌 교내망에서는 열리지 않을 수 있습니다.

실행파일을 열 때 보안 경고가 나와요.

코드 서명이 없는 프로그램이라 Windows SmartScreen 경고가 나올 수 있습니다. 믿을 수 있는 곳에서 받은 파일이라면 추가 정보를 누른 뒤 실행을 누르세요. 학교 PC 정책에 따라 관리자 허용이 필요할 수 있습니다.

건물이 놓이지 않아요.

다른 건물이나 시설과 겹치면 놓을 수 없습니다. 미리보기가 초록색인 자리에 놓거나, 방해되는 항목을 먼저 옮겨 주세요. 나무 같은 소품은 겹쳐도 놓입니다.

교실에 ‘위치 미지정’이 표시돼요.

건물 크기를 줄였거나 빈칸이 없을 때 생깁니다. 다른 교실을 줄여 자리를 만든 뒤, 그 교실을 선택하고 격자의 빈칸을 누르면 됩니다. 위치가 없는 교실은 3D 화면과 위치 점에 나타나지 않습니다.

층수를 줄이면 입력한 교실이 지워지나요?

화면에서만 사라지고 데이터는 남아 있어서, 층수를 다시 늘리면 돌아옵니다.

실수로 지웠어요.

위쪽 되돌리기를 누르면 이전 상태로 돌아갑니다. 페이지를 새로고침하면 되돌리기 기록은 사라지므로 중요한 작업 전에는 제작 파일을 저장해 두세요.

다른 선생님과 함께 작업할 수 있나요?

동시 편집은 지원하지 않습니다. 저장한 제작 파일을 전달하면 다른 컴퓨터에서 열기로 이어서 작업할 수 있습니다.
